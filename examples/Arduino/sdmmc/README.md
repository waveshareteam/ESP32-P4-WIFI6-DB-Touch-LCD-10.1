# SDMMC

[中文](README_CN.md)

Initializes a microSD card over 4-bit SDMMC, prints card and filesystem capacity, and writes and reads `/arduino_test.txt` on the card. Insert a card before running.

## Usage

Select `Waveshare ESP32-P4-WIFI6-DB Touch LCD 10.1`, open `sdmmc.ino`, compile and upload it, and open the serial monitor at 115200 baud. See the [Arduino guide](../README.md) for setup and commands.
