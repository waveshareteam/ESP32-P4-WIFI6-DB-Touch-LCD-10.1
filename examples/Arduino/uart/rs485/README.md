# RS485 Bridge

[中文](README_CN.md)

Bridges the serial monitor and onboard half-duplex RS485 transceiver. The monitor uses 115200 baud; the external device uses 9600 8N1 (TX GPIO27, RX GPIO26, direction GPIO34).

## Usage

Select `Waveshare ESP32-P4-WIFI6-DB Touch LCD 10.1`, open `rs485.ino`, compile and upload it, and open the serial monitor at 115200 baud. See the [Arduino guide](../../README.md) for setup and commands.
