# I2C Scanner

[中文](README_CN.md)

Scans the default I2C bus every five seconds and prints detected 7-bit addresses. The board variant defines SDA as GPIO7 and SCL as GPIO8.

## Usage

Select `Waveshare ESP32-P4-WIFI6-DB Touch LCD 10.1`, open `i2c.ino`, compile and upload it, and open the serial monitor at 115200 baud. See the [Arduino guide](../README.md) for setup and commands.
