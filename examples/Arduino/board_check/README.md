# Board Check

[中文](README_CN.md)

Prints the chip model and revision, CPU information, flash and PSRAM sizes, and free heap once at startup.

## Usage

Select `Waveshare ESP32-P4-WIFI6-DB Touch LCD 10.1`, open `board_check.ino`, compile and upload it, and open the serial monitor at 115200 baud. See the [Arduino guide](../README.md) for setup and commands.
