# TWAI

[中文](README_CN.md)

Receives and prints CAN frames in listen-only mode at 500 kbit/s, accepting all IDs. Connect the interface to a working CAN bus at the same bitrate.

## Usage

Select `Waveshare ESP32-P4-WIFI6-DB Touch LCD 10.1`, open `twai.ino`, compile and upload it, and open the serial monitor at 115200 baud. See the [Arduino guide](../README.md) for setup and commands.
