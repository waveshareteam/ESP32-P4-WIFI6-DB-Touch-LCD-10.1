# Arduino-ESP32 Board Files

[中文](README_CN.md)

This directory contains the board definition and variant for `Waveshare ESP32-P4-WIFI6-DB Touch LCD 10.1`. The project baseline is Arduino-ESP32 3.3.11. `boards.txt` contains this board's definition and menu names; `variants/waveshare_esp32_p4_wifi6_db_touch_lcd_10_1/pins_arduino.h` defines its pins.

See the [Arduino guide](../README.md) for installation, compilation, and upload. The files are board configuration, not a complete Arduino-ESP32 core.
