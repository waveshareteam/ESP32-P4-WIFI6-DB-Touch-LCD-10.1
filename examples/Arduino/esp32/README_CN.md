# Arduino-ESP32 板级文件

[English](README.md)

本目录包含 `Waveshare ESP32-P4-WIFI6-DB Touch LCD 10.1` 的板级定义和 variant。项目以 Arduino-ESP32 3.3.11 为基线。`boards.txt` 包含该板的定义和菜单名称；`variants/waveshare_esp32_p4_wifi6_db_touch_lcd_10_1/pins_arduino.h` 定义引脚。

安装、编译和烧录方法见 [Arduino 指南](../README_CN.md)。这些文件是板级配置，不包含完整的 Arduino-ESP32 core。
